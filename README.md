# lucerna

[specification](spec.md)

**lucerna** (stylized in all lowercase) is a computer that does not exist.

There is an ambition for **lucerna** to actually exist one day. The plan is to eventually use a Tang Nano 9K (or other FPGA) and several other components to manufacture a motherboard PCB. Then to design a 3D printed enclosure for it. Turning it into what is esentially a real computer.
